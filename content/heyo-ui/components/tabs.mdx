# Tabs

`Tabs` switch what is displayed, in place. The moving highlight is pure CSS —
Base UI publishes the active tab's geometry as custom properties, so there is
no measuring in React and no resize observer.

`Tabs.List` renders its own indicator. You never place `Tabs.Indicator`
yourself unless you want it somewhere unusual.

## Usage

```tsx
import { Tabs } from "@heyo-sh/heyo-ui";

<Tabs defaultValue="overview">
  <Tabs.List items={tabs} />
  <Tabs.Panel value="overview">…</Tabs.Panel>
</Tabs>;
```

## Variants

<Properties>
  <Property name="line" type="default">
    A rule runs the full width and the indicator sits on it. The default for
    page-level navigation.
  </Property>
  <Property name="underline" type="variant">
    Padded tabs that highlight on hover, with the indicator detached below a
    hairline.
  </Property>
  <Property name="segmented" type="variant">
    A pill that slides between tabs inside a recessed track. The selected pill
    _is_ the indicator, so there is nothing else to place.
  </Property>
</Properties>

## Composed

Write the tabs out when a row needs more than a label — a count, a status dot,
a router link.

<Callout type="note" title="Tabs or Toggle?">
  Tabs change _what_ is shown. A [`ToggleGroup`](/components/toggle) changes
  _how_ the same thing is shown — grid or list, day or week.
</Callout>

## Properties

### Tabs

<Properties>
  <Property name="variant" type='"line" | "underline" | "segmented"'>
    The shape of the list. It defaults to `line`.
  </Property>
  <Property name="value / defaultValue" type="string">
    Controlled and uncontrolled selection.
  </Property>
  <Property name="onValueChange" type="(value: string) => void">
    Fires when a tab is selected.
  </Property>
  <Property name="orientation" type='"horizontal" | "vertical"'>
    The axis. It defaults to `horizontal`.
  </Property>
</Properties>

### Tabs.List

<Properties>
  <Property name="items" type="TabItem[]">
    Shorthand: `{ value, label, icon?, disabled? }` per tab.
  </Property>
  <Property name="indicator" type="boolean">
    The moving highlight, rendered for you. Pass `false` only to place
    `Tabs.Indicator` somewhere unusual yourself.
  </Property>
</Properties>

### Tabs.Tab, Tabs.Panel, Tabs.Indicator

<Properties>
  <Property name="value" required type="string">
    Ties a tab to its panel.
  </Property>
  <Property name="disabled" type="boolean">
    Dims a tab and ignores interaction.
  </Property>
  <Property name="children" type="ReactNode">
    `Tabs.Panel` holds the content for its value. `Tabs.Indicator` takes no
    children — it is the moving highlight.
  </Property>
</Properties>
