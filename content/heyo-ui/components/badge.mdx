# Badge

Because nothing else in heyo-ui is coloured — the primary button is the inverse
of the page, not blue — a coloured chip means exactly one thing: status. Spend
that carefully.

## Usage

```tsx
import { Badge } from "@heyo-sh/heyo-ui";

<Badge dot variant="success">
  Healthy
</Badge>;
```

## Dots and icons

`dot` puts a coloured dot before the label. It is the quietest way to show
status, and it keeps working for a reader who cannot separate the hues.

<Callout type="note" title="A badge is not a button">
  If it can be clicked it is a [`Button`](/components/button) or a
  [`Toggle`](/components/toggle). A badge reports; it does not act.
</Callout>

## Properties

<Properties>
  <Property
    name="variant"
    type='"neutral" | "outline" | "brand" | "contrast" | "info" | "success" | "warning" | "danger" | "count"'
  >
    The tone. It defaults to `neutral`.
  </Property>
  <Property name="size" type='"sm" | "base"'>
    It defaults to `base`.
  </Property>
  <Property name="dot" type="boolean">
    Draws a status dot before the label.
  </Property>
  <Property name="icon" type="IconLike">
    A leading glyph — a component, an element, or any node.
  </Property>
  <Property name="children" type="ReactNode">
    The label.
  </Property>
  <Property name="className" type="string">
    Merged through `tailwind-merge`.
  </Property>
</Properties>

### badgeVariants

The `cva` definition behind the component, for the rare case something else has
to look exactly like a badge.

```tsx
import { badgeVariants } from "@heyo-sh/heyo-ui";

<span className={badgeVariants({ variant: "success", dot: true })}>Live</span>;
```
