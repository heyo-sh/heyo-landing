# Toggle

A `Toggle` is a button that stays pressed: bold in an editor, a filter chip, a
view mode. On its own it is a single on/off control; inside a `ToggleGroup` it
becomes one of a set.

## Usage

```tsx
import { Toggle, ToggleGroup } from "@heyo-sh/heyo-ui";

<ToggleGroup defaultValue={["grid"]} attached>
  <Toggle value="grid" variant="outline" icon={IconGrid} aria-label="Grid" />
  <Toggle value="list" variant="outline" icon={IconList} aria-label="List" />
</ToggleGroup>;
```

## Variants and sizes

`ghost` is the default — invisible until hovered, which is what an editor
toolbar wants. `outline` draws its own edge and suits a standalone filter.

## Single or multiple

A group is single-choice by default. Pass `multiple` and it behaves like a set
of checkboxes — several filters at once.

## Attached and equal

`attached` welds the buttons into one control, the way
[`ButtonGroup`](/components/button) does. `equal` gives every toggle the width
of the widest one — on by default for a vertical group, where ragged right
edges look like a mistake rather than a choice.

<Callout type="note" title="Toggle, Tabs or Radio?">
  A toggle group changes how something is _displayed_.
  [`Tabs`](/components/tabs) change what is displayed.
  [`Radio`](/components/radio) collects a value you are going to submit.
</Callout>

## Properties

### Toggle

<Properties>
  <Property name="value" type="string">
    The value this toggle contributes inside a group.
  </Property>
  <Property name="pressed / defaultPressed" type="boolean">
    Controlled and uncontrolled state, for a standalone toggle.
  </Property>
  <Property name="onPressedChange" type="(pressed: boolean) => void">
    Fires when the toggle flips.
  </Property>
  <Property name="variant" type='"ghost" | "outline"'>
    It defaults to `ghost`.
  </Property>
  <Property name="size" type='"xs" | "sm" | "base"'>
    It defaults to `base`.
  </Property>
  <Property name="square" type="boolean">
    Forces a square, icon-only shape. Implied when there is no label.
  </Property>
  <Property name="icon" type="IconLike">
    The glyph — a component, an element, or any node.
  </Property>
  <Property name="disabled" type="boolean">
    Dims the control and ignores interaction.
  </Property>
</Properties>

### ToggleGroup

<Properties>
  <Property name="value / defaultValue" type="string[]">
    Controlled and uncontrolled selection. Always an array, even when single.
  </Property>
  <Property name="onValueChange" type="(value: string[]) => void">
    Fires when the selection changes.
  </Property>
  <Property name="multiple" type="boolean">
    Allows several toggles to be pressed at once.
  </Property>
  <Property name="attached" type="boolean">
    Welds the buttons into a single control.
  </Property>
  <Property name="equal" type="boolean">
    Gives every toggle the width of the widest. It defaults to `true` for
    `vertical`, `false` for `horizontal`.
  </Property>
  <Property name="orientation" type='"horizontal" | "vertical"'>
    The layout axis. It defaults to `horizontal`.
  </Property>
  <Property name="disabled" type="boolean">
    Dims every toggle in the group.
  </Property>
</Properties>
