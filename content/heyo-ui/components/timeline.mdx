# Timeline

The rail is **one continuous line** drawn by the list and masked at both ends,
not a stack of per-item segments: segments leave hairline seams between entries
that you can see the moment two markers have different tones.

It fades out at the bottom, because an event feed almost never _ends_ — it just
stops being loaded, and a line that stops dead implies otherwise.

## Usage

```tsx
import { Timeline } from "@heyo-sh/heyo-ui";

<Timeline>
  <Timeline.Item title="Build passed" time="2m ago" tone="success" />
</Timeline>;
```

## Density

`full` gives every entry an icon-sized marker. `compact` uses a dot on a
hairline rail, which is what an audit log with fifty rows wants. Set it on the
list; the items inherit it.

## Day separators

`Timeline.Separator` is a heading between entries, and it is **sticky** —
scrolling a month of deploys never leaves you wondering which day you are
looking at.

## Properties

### Timeline

<Properties>
  <Property name="density" type='"full" | "compact"'>
    `full` gives every entry an icon-sized marker; `compact` uses a dot on a
    hairline rail. It defaults to `full`.
  </Property>
</Properties>

### Timeline.Item

<Properties>
  <Property name="title" required type="ReactNode">
    The headline of the entry.
  </Property>
  <Property name="time" type="ReactNode">
    Right-aligned and muted — a timestamp, a duration, an actor.
  </Property>
  <Property name="icon" type="IconLike">
    Rendered inside the marker. It falls back to a dot.
  </Property>
  <Property
    name="tone"
    type='"neutral" | "brand" | "info" | "success" | "warning" | "danger"'
  >
    The marker's colour. It defaults to `neutral`.
  </Property>
  <Property name="active" type="boolean">
    Draws attention to the entry that is still happening: the marker gets a slow
    halo and the row a faint tint.
  </Property>
  <Property name="density" type='"full" | "compact"'>
    Match the `density` set on the list.
  </Property>
  <Property name="children" type="ReactNode">
    The body under the title.
  </Property>
</Properties>

### Timeline.Separator

<Properties>
  <Property name="children" type="ReactNode">
    A sticky heading between entries — usually a date.
  </Property>
</Properties>
