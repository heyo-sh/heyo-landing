# Heyo Status

Heyo Status is a status page you own. It checks your services on a schedule,
keeps uptime history, publishes incidents and maintenance windows, and can
notify your team and subscribers. A single `heyo-status.config.ts` powers the
page, HTTP API, scheduler and CLI.

Start with the [Quickstart](https://heyo.sh/heyo-status/quickstart), then set up
[monitors](https://heyo.sh/heyo-status/manage-status-page/monitors) and choose a
[theme](https://heyo.sh/heyo-status/manage-status-page/themes). The generated project
includes a database adapter and deployment files for your platform; the status
page is rendered on the server so visitors can still read it without JavaScript.
