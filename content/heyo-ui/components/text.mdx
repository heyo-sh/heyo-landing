# Text

Almost everything in an application is 14px. Hierarchy is carried by **weight
and colour**, not by size — which is why `Text` has a `tone` and a `weight`
prop, and why its `size` prop is the one you reach for least.

- **Medium** names a surface or a group: field labels, section labels, card
  titles, table headers.
- **Normal** is everything living inside one: button labels, navigation items,
  table cells, body copy.
- `text-heyo-default` is the thing being acted on. `text-heyo-subtle` is
  context.

## Usage

```tsx
import { Text } from "@heyo-sh/heyo-ui";

<Text tone="subtle">Last deployed 4 minutes ago</Text>;
```

## Sizes

statement; `2xl` and `3xl` are for a page title or a number, not for a
paragraph.

## Mono and truncate

`mono` switches to the monospace stack — identifiers, hashes, regions.
`truncate` clips to one line with an ellipsis, and sets the `min-width: 0` that
makes truncation work inside a flex row.

<CodeSnippet
  previewClassName="heyo-ui flex-col gap-1"
  code={`<Text mono tone="subtle">dpl_8f21c3d9</Text>
<Text truncate>A single line that is far too long to fit in the space it has been given</Text>`}
>
  <HeyoUiText mono tone="subtle">
    dpl_8f21c3d9
  </HeyoUiText>
  <div className="w-full max-w-xs">
    <HeyoUiText truncate>
      A single line that is far too long to fit in the space it has been given
    </HeyoUiText>
  </div>
</CodeSnippet>

## Heading

`Heading` renders `h1` to `h6` with the right size for the level. `as` on
`Text` does the same job when you need a different element without a heading's
semantics.

## Code

Inline code on the recessed surface. It pairs with [`Kbd`](/components/kbd) for
shortcut documentation and with [`CodeBlock`](/components/code-block) for
anything longer than a phrase.

  </HeyoUiText>

## Properties

### Text

<Properties>
  <Property
    name="size"
    type='"xs" | "sm" | "base" | "lg" | "xl" | "2xl" | "3xl"'
  >
    It defaults to `base` (14px).
  </Property>
  <Property
    name="tone"
    type='"default" | "strong" | "subtle" | "inactive" | "inverse" | "brand" | "success" | "warning" | "danger"'
  >
    It defaults to `default`.
  </Property>
  <Property name="weight" type='"normal" | "medium" | "semibold"'>
    It defaults to `normal`.
  </Property>
  <Property name="mono" type="boolean">
    Switches to the monospace stack.
  </Property>
  <Property name="truncate" type="boolean">
    One line with an ellipsis, including the `min-width: 0` it needs.
  </Property>
  <Property name="as" type="ElementType">
    Render a different element: `as="span"`, `as="label"`.
  </Property>
</Properties>

### Heading

<Properties>
  <Property name="level" type="1 | 2 | 3 | 4 | 5 | 6">
    The heading level and its size. It defaults to `2`.
  </Property>
</Properties>

### Code

<Properties>
  <Property name="children" type="ReactNode">
    Inline code, on the recessed surface.
  </Property>
</Properties>

### textVariants

The `cva` definition, for anything that needs the same type without the
component.

```tsx
import { textVariants } from "@heyo-sh/heyo-ui";

<time className={textVariants({ size: "sm", tone: "subtle" })}>4m ago</time>;
```
