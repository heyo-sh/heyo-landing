# Popover

Three components float above the page, and they do different jobs:

- [`Tooltip`](/components/tooltip) for a **label** — a few words, no
  interaction.
- [`Dropdown`](/components/dropdown) for a **list of actions**.
- `Popover` for anything with its **own layout**: filters, a form, a preview, a
  short explanation with a link in it.

## Usage

```tsx
import { Button, Popover } from "@heyo-sh/heyo-ui";

<Popover>
  <Popover.Trigger render={<Button>Filters</Button>} />
  <Popover.Content title="Filters">…</Popover.Content>
</Popover>;
```

## Header and close

Passing `title` (and optionally `description`) renders the heading block and a
close button for you. Without them the popup is a bare surface and you own
every pixel of it.

## Placement

`side` and `align` set the preferred position; it flips and shifts on its own
when the space is not there.

## Properties

### Popover

Base UI's root: `open`, `defaultOpen`, `onOpenChange`, plus the usual
interaction props.

### Popover.Content

<Properties>
  <Property name="title" type="ReactNode">
    A heading above the content. Its presence also adds the close button.
  </Property>
  <Property name="description" type="ReactNode">
    A muted line under the title.
  </Property>
  <Property name="showClose" type="boolean">
    Forces the close button on or off.
  </Property>
  <Property name="side" type='"top" | "right" | "bottom" | "left"'>
    Preferred placement.
  </Property>
  <Property name="align" type='"start" | "center" | "end"'>
    Alignment against the trigger.
  </Property>
  <Property name="sideOffset" type="number">
    Gap between trigger and popup, in pixels.
  </Property>
  <Property name="positioner" type="Popover.Positioner.Props">
    Escape hatch for anything else the positioner supports.
  </Property>
  <Property name="className" type="string">
    Merged into the popup — a different width, more padding.
  </Property>
</Properties>

### The rest

<Properties>
  <Property name="Popover.Trigger" type="render">
    Anything that opens it.
  </Property>
  <Property name="Popover.Close" type="render">
    Closes it from inside the content.
  </Property>
  <Property name="Popover.Title / Description" type="—">
    The raw parts, when you would rather build the header yourself.
  </Property>
</Properties>
