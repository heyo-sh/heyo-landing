# Heyo Docs

Heyo Docs is an open-source project for developer documentation. It helps you
create clear sites with guides, API references, and resources for technical
teams — from the first MDX page to a published documentation site.

The project combines a content pipeline, navigation, and a polished
documentation interface with your chosen framework. It also prepares your docs
for search engines and AI agents with a sitemap, `robots.txt`, RSS, and
[LLMs files](https://heyo.sh/heyo-docs/tutorials/llms-txt). Start with the [Quickstart](https://heyo.sh/heyo-docs/quickstart), then
learn how to set up branding, navigation, and content in the
[configuration guide](https://heyo.sh/heyo-docs/manage-website/configuration).
