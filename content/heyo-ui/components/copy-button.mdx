# Copy Button

`CopyButton` is a [`Button`](/components/button) that writes a string to the
clipboard and then says so: the icon becomes a tick and stays that way long
enough to be believed. Without the hold, a copy button is indistinguishable
from a button that did nothing.

It takes every `Button` prop except `icon` and `onClick` — those two are what
the component is. A labelled button also swaps its own text for "Copied" while
the tick is up, and it falls back to the old `execCommand` trick when the
Clipboard API is unavailable, so it still works over plain HTTP.

## Usage

```tsx
import { CopyButton } from "@heyo-sh/heyo-ui";

<CopyButton value={deployment.id} variant="ghost" shape="square" />;
```

## Icon only or labelled

Omit `children` for an icon-only button — it is square automatically and
announces itself as "Copy" to a screen reader. Pass a label when the button
sits on its own and the icon has no context to borrow from.

## In a row

The usual home for a copy button is the end of a row holding an identifier —
quiet enough to ignore, close enough to hit.

## Properties

<Properties>
  <Property name="value" required type="string">
    The text put on the clipboard.
  </Property>
  <Property name="children" type="ReactNode">
    The label beside the icon. Omit it for an icon-only button.
  </Property>
  <Property name="timeout" type="number">
    How long the tick stays, in milliseconds. It defaults to `1600`.
  </Property>
  <Property name="onCopy" type="(value: string) => void">
    Fires after a successful write — for analytics or a toast.
  </Property>
  <Property name="label" type="string">
    The accessible name when there is no visible label. It defaults to `"Copy"`.
  </Property>
  <Property name="variant / size / shape" type="ButtonProps">
    Every `Button` appearance prop. `variant` defaults to `ghost`, `size` to
    `sm`, and `shape` to `square` whenever there is no label.
  </Property>
</Properties>
