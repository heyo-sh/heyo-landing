# Stat

The value is the only large type in the component and the only thing at full
contrast. A stat where the label competes with the number is a stat nobody
reads at a glance.

## Usage

```tsx
import { Stat } from "@heyo-sh/heyo-ui";

<Stat
  label="Requests"
  value="142,318"
  delta={12.4}
  deltaLabel="vs last week"
/>;
```

## Deltas

`delta` is a **number**, not a string: `-4.2` renders as "−4.2%" and the sign
picks the colour. `deltaGood={false}` flips that mapping — for latency, error
rate or spend, where up is exactly what you did not want.

## Bordered, and with a chart

`bordered` adds the hairline and the surface. It is off by default so a stat
can sit inside a [`Card`](/components/card) without drawing a second box.
`chart` is the slot under the numbers — a sparkline, a
[`Meter`](/components/meter), a [`StatusBar`](/components/status-bar).

## Groups

`Stat.Group` separates stats with hairlines rather than gaps — the dashboard
header pattern. Dividers instead of cards, so the row reads as one band.

<Callout type="note" title="A stat is not a metric chart">
  It answers "what is it now, and which way is it going". For the shape over
  time, put a sparkline in `chart`.
</Callout>

## Properties

### Stat

<Properties>
  <Property name="label" required type="ReactNode">
    What the number is.
  </Property>
  <Property name="value" required type="ReactNode">
    The number itself — the only large type in the component.
  </Property>
  <Property name="unit" type="ReactNode">
    A unit or qualifier printed after the value, smaller and muted.
  </Property>
  <Property name="delta" type="number">
    Change against the previous period, as a number. The sign decides the
    colour.
  </Property>
  <Property name="deltaGood" type="boolean">
    Whether a rise is good. It defaults to `true`; pass `false` for latency,
    errors or spend.
  </Property>
  <Property name="deltaUnit" type="string">
    The suffix on the delta. It defaults to `"%"`.
  </Property>
  <Property name="deltaLabel" type="ReactNode">
    What the delta is measured against, for example "vs last week".
  </Property>
  <Property name="icon" type="IconLike">
    A small glyph beside the label.
  </Property>
  <Property name="chart" type="ReactNode">
    The slot under the numbers.
  </Property>
  <Property name="bordered" type="boolean">
    Adds the hairline and surface. Off by default.
  </Property>
</Properties>

### Stat.Group

<Properties>
  <Property name="columns" type="2 | 3 | 4">
    Columns on a wide screen. It defaults to `3`.
  </Property>
</Properties>
