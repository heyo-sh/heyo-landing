# Button

`Button` is 32px tall by default and draws its edge with a `ring`, not a
border — so a variant change never shifts the layout by a pixel and buttons sit
flush inside a group.

`primary` is the inverse of the page: black on light, white on dark. There is
no coloured accent anywhere in the system, which leaves hue free to mean
exactly one thing — status.

## Usage

```tsx
import { Button } from "@heyo-sh/heyo-ui";

<Button variant="primary" icon={IconPlus}>
  Create worker
</Button>;
```

is _about_ deleting. `destructive-secondary` is the row-level version — the one
that opens that dialog.

## Sizes

20, 26, 32 and 40px. `base` is the default and the height every other control
in the library shares.

## Icons

`icon` and `iconEnd` accept a component, an element, or any node — heyo-ui
ships no icon dependency. The control sizes the glyph; never do it yourself.

## Loading and disabled

`loading` swaps the leading icon for a spinner and blocks interaction, so the
label stays put and the button keeps its width.

## As a link

`render` swaps the element while keeping every bit of styling — the way to turn
a button into an anchor or a router link.

```tsx
<Button render={<a href="/docs" />}>Read the docs</Button>
<Button render={<Link to="/workers" />} variant="primary">Workers</Button>
```

## ButtonGroup

Welds buttons into a single control: shared edges collapse, only the outer
corners stay rounded, and the hovered or focused button floats above its
neighbours so its ring is never clipped.

<Callout type="note" title="A group is not a choice">
  `ButtonGroup` welds actions together. For a set that remembers which one is
  selected, use [`ToggleGroup`](/components/toggle) instead.
</Callout>

## Properties

<Properties>
  <Property
    name="variant"
    type='"primary" | "secondary" | "outline" | "ghost" | "destructive" | "destructive-secondary" | "link"'
  >
    The visual weight. It defaults to `secondary`.
  </Property>
  <Property name="size" type='"xs" | "sm" | "base" | "lg"'>
    20, 26, 32 or 40px tall. It defaults to `base`.
  </Property>
  <Property name="shape" type='"default" | "square" | "block"'>
    `square` is icon-only, `block` fills the container. It defaults to
    `default`.
  </Property>
  <Property name="icon" type="IconLike">
    Rendered before the label — or as the only content when
    `shape="square"`.
  </Property>
  <Property name="iconEnd" type="IconLike">
    Rendered after the label.
  </Property>
  <Property name="loading" type="boolean">
    Swaps the leading icon for a spinner and blocks interaction.
  </Property>
  <Property name="disabled" type="boolean">
    The native disabled state.
  </Property>
  <Property name="render" type="RenderProp">
    Renders a different element with the same styling — an `<a>`, a router
    link.
  </Property>
  <Property name="className" type="string">
    Merged through `tailwind-merge`, so `rounded-full px-6` is a pill.
  </Property>
</Properties>

### ButtonGroup

<Properties>
  <Property name="orientation" type='"horizontal" | "vertical"'>
    Stacks the buttons instead of placing them side by side. It defaults to
    `horizontal`.
  </Property>
</Properties>

### buttonVariants

The `cva` definition behind the component, exported for the rare case where
something that is not a button has to look exactly like one.

```tsx
import { buttonVariants } from "@heyo-sh/heyo-ui";

<a className={buttonVariants({ variant: "outline", size: "sm" })}>Docs</a>;
```
