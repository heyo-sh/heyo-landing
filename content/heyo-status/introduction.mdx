# Heyo Status

Heyo Status gives you a status page in your own app. It checks your services,
keeps uptime history and publishes incidents and planned maintenance. You can
also send updates to your team and subscribers. The page, API and scheduler
share one `heyo-status.config.ts` file.

To get a page running, use [create-heyo-status](https://heyo.sh/heyo-status/quickstart).
The generator supplies the framework routes, database adapter and deployment
scheduler together; installing the runtime package alone does not produce a
working status page. Then replace the example
[monitors](https://heyo.sh/heyo-status/manage-status-page/monitors) and choose
a [theme](https://heyo.sh/heyo-status/manage-status-page/themes). Visitors
can read the server-rendered page without JavaScript.

Pick the framework you use. Each starter exposes the same status API and
reads the same configuration file.

Once the page is running, set your [check schedule](https://heyo.sh/heyo-status/manage-status-page/checks)
and deploy to [Cloudflare](https://heyo.sh/heyo-status/deploying/cloudflare),
[Vercel](https://heyo.sh/heyo-status/deploying/vercel), or
[your own server](https://heyo.sh/heyo-status/deploying/self-hosting).
