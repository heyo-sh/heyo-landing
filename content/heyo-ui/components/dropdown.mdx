# Dropdown

`Dropdown` is a menu of actions anchored to a trigger. Rows are 20px-guttered
so icons, check marks and radio dots all line up, whatever a given menu mixes.

**It does not lock the page.** `modal` defaults to `false`, which is not Base
UI's default: a menu is a list of things you might not do, and freezing the
application behind one feels broken — and if the unlock ever misses, it stays
broken.

## Usage

```tsx
import { Button, Dropdown } from "@heyo-sh/heyo-ui";

<Dropdown>
  <Dropdown.Trigger render={<Button>Actions</Button>} />
  <Dropdown.Content>
    <Dropdown.Item onClick={rename}>Rename</Dropdown.Item>
  </Dropdown.Content>
</Dropdown>;
```

## From data

`items` builds the whole menu — rows, separators and titled sections — from an
array. The string `"separator"` is a rule; an entry with `items` is a section.

## Checkbox and radio items

A menu is also where small, immediate settings live. Radio items draw their own
dot on the same 20px gutter the checkbox items use, so a mixed menu stays
aligned.

<Callout type="note" title="Menu, list, or palette?">
  `Dropdown` is for actions. [`Select`](/components/select) is for choosing a
  value, [`Combobox`](/components/combobox) when that list needs filtering, and
  [`Command`](/components/command) when the answer is "anything in the
  application".
</Callout>

## Properties

### Dropdown

<Properties>
  <Property name="modal" type="boolean">
    Whether the open menu locks the page. It defaults to `false`, unlike Base
    UI.
  </Property>
  <Property name="open" type="boolean">
    Controlled state. Pair it with `onOpenChange`.
  </Property>
  <Property name="defaultOpen" type="boolean">
    Open on first render.
  </Property>
  <Property name="onOpenChange" type="(open: boolean) => void">
    Fires on open and close.
  </Property>
</Properties>

### Dropdown.Content

<Properties>
  <Property name="items" type="DropdownEntry[]">
    Shorthand. An entry is a row (`label`, `icon`, `shortcut`, `destructive`,
    `disabled`, `onClick`), the string `"separator"`, or a section (`label` plus
    nested `items`).
  </Property>
  <Property name="side" type='"top" | "right" | "bottom" | "left"'>
    Preferred placement. It flips when there is no room.
  </Property>
  <Property name="align" type='"start" | "center" | "end"'>
    Alignment against the trigger. It defaults to `start`.
  </Property>
  <Property name="sideOffset" type="number">
    Gap between the trigger and the menu, in pixels. It defaults to `4`.
  </Property>
  <Property name="positioner" type="Menu.Positioner.Props">
    Escape hatch for anything else the positioner supports.
  </Property>
</Properties>

### Dropdown.Item

<Properties>
  <Property name="icon" type="IconLike">
    The leading glyph.
  </Property>
  <Property name="shortcut" type="ReactNode">
    A right-aligned hint, usually a [`Kbd`](/components/kbd).
  </Property>
  <Property name="destructive" type="boolean">
    Red styling for an irreversible action.
  </Property>
  <Property name="disabled" type="boolean">
    Dims the row and ignores interaction.
  </Property>
  <Property name="onClick" type="() => void">
    Runs when the row is chosen.
  </Property>
</Properties>

### The rest

<Properties>
  <Property name="Dropdown.Trigger" type="render">
    Anything that opens the menu. Pass `render={<Button />}` to use a button.
  </Property>
  <Property name="Dropdown.CheckboxItem" type="checked, onCheckedChange">
    A togglable row with a check mark in the gutter.
  </Property>
  <Property name="Dropdown.RadioGroup / RadioItem" type="value, onValueChange">
    A single choice. The dot is drawn by heyo-ui, on the checkbox gutter.
  </Property>
  <Property name="Dropdown.Group / Label / Separator" type="—">
    A titled section, its heading, and a rule.
  </Property>
  <Property name="Dropdown.Sub / SubTrigger / SubContent" type="—">
    A nested menu. `SubContent` takes the same props as `Content`.
  </Property>
</Properties>
